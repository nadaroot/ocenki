# Кастомный Электронный Дневник (e-schools.by)

Адаптивное веб-приложение для мониторинга успеваемости с интеграцией с `e-schools.by` (schools.by), строгим OLED-черным дизайном, калькулятором стратегии отметок и готовой DevOps-инфраструктурой для бесплатного деплоя с автоматическим SSL-сертификатом.

---

## 1. Возможности и разделы

- **Главная (Дашборд)**:
  - Общий средний балл (GPA) с индикатором недельной динамики.
  - Векторный интерактивный график успеваемости по дням с подсказками (SVG).
  - Блок «Критические предметы» — автоматическое выявление предметов, где падает балл или оценка близка к нижней границе.
  - Счетчик оставшихся дней до окончания текущей четверти и прогресс-бар четверти (I, II, III, IV четверти).
- **Предметы**:
  - Полный перечень школьных дисциплин с текущим средним баллом, количеством отметок и трендом.
  - Поиск и сортировка предметов (по алфавиту, по среднему баллу, по числу оценок).
  - Детальное модальное окно: хронологический список всех отметок с датами и темами уроков, мини-график динамики.
  - **Калькулятор стратегии**: расчет точного количества отметок (10, 9, 8), необходимых для достижения целевого балла.
  - **Симулятор оценок («Что если»)**: интерактивное добавление гипотетических оценок с мгновенным пересчетом прогнозируемого балла.
- **Расписание**:
  - Чистый список уроков на неделю, спарсенный с дневника.
  - Быстрое переключение по дням недели (Пн, Вт, Ср, Чт, Пт).
  - Время звонков, номер урока, название предмета, кабинет, преподаватель и домашнее задание.
- **Профиль / Настройки**:
  - Настройки подключения к e-schools.by (поддомен школы, логин, пароль либо сессионная cookie).
  - Кнопка принудительного обновления («Синхронизировать данные»).
  - Встроенный демонстрационный режим (Mock Mode) для работы без учетных данных.
  - Безопасный выход с очисткой локального кеша.
- **UI/UX**:
  - Строгий минималистичный черный стиль (`#000000`, OLED-оптимизированный).
  - Отсутствие эмодзи и стикеров — только строгие векторные иконки Lucide.
  - Мобильная адаптация: Bottom Navigation Bar внизу экрана с учетом безопасных зон (`safe-area-inset`), Sidebar на десктопе.

## 2. Локальный запуск

### Вариант А: Запуск через Node.js
```bash
# Установка зависимостей
npm install

# Запуск режима разработки
npm run dev
```
Приложение откроется по адресу: `http://localhost:3000`

### Вариант Б: Запуск в Docker Compose
```bash
docker-compose up --build
```

## 3. Деплой на бесплатный хостинг с бесплатным SSL

### Вариант 1: Деплой на Vercel (Бесплатный домен *.vercel.app + SSL)
1. Создайте репозиторий на GitHub и отправьте в него код проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/electro-dnevnik.git
   git push -u origin main
   ```
2. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub.
3. Нажмите **Add New...** -> **Project** и импортируйте репозиторий `electro-dnevnik`.
4. Файл `vercel.json` уже настроен. Нажмите **Deploy**.
5. Через 1 минуту приложение будет доступно по адресу вида `https://electro-dnevnik.vercel.app` с автоматическим бесплатным SSL-сертификатом.

---

### Вариант 2: Деплой на Render (Бесплатный домен *.onrender.com + Docker + SSL)
1. Зарегистрируйтесь на [render.com](https://render.com).
2. Нажмите **New +** -> **Web Service**.
3. Выберите ваш GitHub-репозиторий `electro-dnevnik`.
4. В качестве Runtime выберите **Docker** (Render автоматически использует готовый `Dockerfile` и `render.yaml`).
5. Выберите тариф **Free**.
6. Нажмите **Create Web Service**.
7. Render соберет оптимизированный образ и предоставит бесплатный защищенный субдомен вида `https://electro-dnevnik.onrender.com`.

---

### Вариант 3: Деплой на Railway или Fly.io
Проект содержит многоэтапный `Dockerfile` с автономной сборкой (`output: 'standalone'`).
- **Railway**: импортируйте репозиторий, Railway автоматически обнаружит `Dockerfile` и развернет контейнер с бесплатным SSL.
- **Fly.io**: выполните `fly launch` в корне проекта.

## 4. Конфигурация (.env)

Скопируйте пример файла конфигурации:
```bash
cp .env.example .env.local
```

Переменные:
- `PORT` — порт сервера (по умолчанию `3000`).
- `NEXT_PUBLIC_ENABLE_MOCK_FALLBACK` — разрешение использования демонстрационных данных при недоступности e-schools (`true` / `false`).
- `ESCHOOLS_BASE_URL` — базовый адрес системы (по умолчанию `https://schools.by`).
- `ESCHOOLS_REQUEST_TIMEOUT` — таймаут сетевых запросов (в миллисекундах).

```
├── render.yaml                 # Blueprint деплоя на Render
├── .env.example                # Шаблон переменных окружения
└── src/
    ├── app/
    │   ├── api/
    │   │   ├── eschools/sync/  # Серверный прокси-парсер e-schools.by
    │   │   └── eschools/test/  # Healthcheck для Docker/Render
    │   ├── globals.css         # OLED черная тема и стили
    │   ├── layout.tsx          # Root Layout c PWA мета-тегами
    │   └── page.tsx            # Контроллер вкладок и интерфейса
    ├── components/
    │   ├── Navigation/         # Sidebar (ПК) и BottomNav (Мобильные)
    │   ├── Dashboard/          # GPA, SVG-график, критические предметы, четверти
    │   ├── Subjects/           # Журнал дисциплин, модальное окно, калькулятор
    │   ├── Schedule/           # Недельное расписание уроков
    │   └── Settings/           # Управление e-schools и сессией
    └── lib/
        ├── eschools/           # Клиент, типы, калькулятор, хранилище, мок-данные
        └── utils.ts            # Оформление оценок и форматирование
```
